# Nkya Privacy Policy (draft)

Nkya is an Android launcher. It does not include analytics, advertising or crash-reporting SDKs, and it does not create accounts.

**Stays on your device:** your home screen layout, settings, icon choices and app lists.

**Permissions you can grant (optional):** notification access (for notification dots), usage access (for app suggestions), and accessibility / device admin (for gestures such as double-tap to lock). These are used on the device only.

**Network use:**
- Nkya periodically downloads a small public file, `live-information.json`, from this GitHub repository (`raw.githubusercontent.com`). It can contain announcements and default feature settings. GitHub can see your IP address when this happens. You can turn this off under Settings → General → Live information.
- Search, web, weather and app-store features open third-party services (for example Google or your chosen search provider) when you use them. Their privacy policies apply.
- If you choose to share a bug report, it is uploaded to a third-party paste service (katb.in) and the link is shared by you.

Nkya is based on Lawnchair and the Android Open Source Project. Contact: open an issue at https://github.com/domusdeiug/nkya/issues.
